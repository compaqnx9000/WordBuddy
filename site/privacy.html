隐私保护指引（隐私政策）

更新日期：2026年10月16日 生效日期：2026年10月16日 「你的词搭子」（以下简称「本应用」）由北京博冠鸿图科技有限公司（以下简称「我们」）运营。我们深知个人信息对你的重要性，将按法律法规要求保护你的个人信息。请在使用前仔细阅读本指引。你点击同意或继续使用，即表示你已理解并同意我们按本指引处理相关信息。 本指引同时说明各端实际上架版本处理的个人信息。我们不出售个人信息，也不将下列信息用于追踪。追踪是指把你的信息与其他公司的数据关联，用于跨应用定向广告或与数据中间商共享。 一、我们收集的个人信息 我们只收集实现功能所必需的信息。你可以不登录，仅使用查词和系统词书。登录后，下列信息与你的账号关联，用于 App 功能；其中使用时长和短视频观看还用于本应用内的学习推荐。这些信息不用于追踪。 1. 姓名：你设置的昵称。 2. 电子邮件地址：你自愿填写的邮箱。不填不影响使用。 3. 电话号码：注册、登录所用手机号；兑换实物礼品时你填写的收件电话。 4. 实际地址：仅在你兑换实物礼品并填写收件地址时收集，用于发货。 5. 粗略位置：你在个人资料里自行选择的省或地区。我们不申请定位权限，不收集 GPS 或精确位置。 6. 照片或视频：你主动拍摄或从相册选择的头像。 7. 其他用户内容：生词本、收藏的词条、签名。 8. 搜索历史记录：你在本应用中查过的单词。登录后与账号一并保存，用于生词本和学习记录。 9. 用户 ID：系统分配的搭子号，以及为登录、同步所必需的账号标识。 10. 产品交互：前台使用时长、短视频观看情况。用于学习等级，以及在本应用内推荐学习内容。 11. 其他数据：你自愿填写的性别。不填不影响使用。 我们不收集通讯录、健康与健身信息、精确位置、支付卡号、广告标识符或设备广告 ID。面容 ID 或触控 ID 只在你的设备上用于解锁，生物特征不会上传。 二、我们如何使用 1. App 功能：注册登录、词库同步、生词本、签到与搭币、礼品发货、账号安全、客户服务。 2. 产品个性化：仅根据你在本应用内的使用时长和短视频观看，推荐学习内容。不与其他公司的数据合并，不用于广告。 3. 安全：根据 IP、设备型号、操作系统版本、应用版本和网络类型排查故障、防范滥用。这些日志不用于追踪。 三、权限 相机和相册只在你主动更换头像时由系统征求授权，可在系统设置中关闭。我们不会在后台擅自开启。 四、广告 1. Android 版本：在你同意本隐私政策后，为实现开屏、短视频信息流与激励视频广告，本应用会接入穿山甲（GroMore）及相关广告 SDK。相关 SDK 仅在加载或展示广告时按需处理设备与广告交互信息；我们已按平台能力关闭非必要权限读取。建议你同时阅读对应 SDK 隐私政策。 2. 在 App Store 提供的 iOS 版本不展示开屏、信息流或激励视频广告，不接入广告 SDK，不读取广告标识符，也不将个人信息用于追踪。 五、我们如何存储与保护 1. 账号、生词、订单等个人信息存储在中华人民共和国境内的服务器。 2. 查词时，所查单词会发送给词典服务以返回释义；你主动生成助记配图时，所查单词会发送给图像服务以生成图片。这两次传输不附带手机号或搭子号。 3. 我们采用合理的技术与管理措施保护信息安全，但请理解任何互联网传输与存储都无法保证绝对安全。 4. 我们仅在实现目的所必需的期限内保存。账号注销完成或法定保存期限届满后，将删除或匿名化处理，法律另有要求的除外。 六、我们如何共享、转让、公开披露 1. 我们不会出售你的个人信息，也不会为追踪而向数据中间商或广告网络共享。 2. 仅为完成对应功能，我们可能向受托方提供必要信息，并要求其不得用于约定以外的目的： （1）短信服务商：手机号，用于发送验证码； （2）境内云服务：账号与学习数据的存储和同步； （3）词典服务：你正在查询的单词； （4）图像服务：你主动要求生图时的单词； （5）第三方 SDK：见下文「七、接入的第三方 SDK」所列主体，仅在你使用对应功能或同意广告服务后处理必要信息。 3. 支付如由支付宝或微信完成，付款信息在对应支付客户端内输入。我们不收集、不保存你的银行卡号。 4. 转让：如发生合并、收购或破产，我们将要求承继方继续受本指引约束，否则将重新征得同意。 5. 公开披露：仅在获得你的单独同意，或法律法规、司法机关、行政机关依法要求时进行。 七、接入的第三方 SDK 为实现登录、支付、广告等功能，Android 版本可能接入下列第三方 SDK。公示信息与全国 SDK 管理服务平台（https://sdk.caict.ac.cn/official/#/home）登记情况保持一致。各 SDK 仅在对应业务场景下按需处理信息，具体以其官方隐私政策为准。 1.
